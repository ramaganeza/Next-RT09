# Panduan RT/RW baru memakai SIRUTA

1. Salin repositori, edit `src/config.js` dengan kunci Supabase milik RT/RW Anda (jangan memakai kunci RT lain).
2. Jalankan berkas SQL dasar di Supabase SQL Editor (folder `supabase/`). Jangan unggah berkas bernama *RAHASIA* ke GitHub.
3. Aktifkan GitHub Pages (Settings > Pages > Source: GitHub Actions), lalu buka alamat situs.
4. Masuk sebagai pengurus, buka **Pengaturan > Umum**, ikuti checklist **Setelan awal**:
   Identitas & wilayah; Pejabat & tanda tangan (nama Ketua RT/RW, unggah TTD, tempat surat); Logo & nama aplikasi; Rekening & WhatsApp Bendahara; Nominal iuran; Jadwal pertemuan; Nomor & kode surat; Visi, struktur & SOP.
5. Impor data warga, lalu coba buat satu surat dan periksa tampilan kop, TTD, dan kolom "Mengetahui".
6. Bila tampilan tidak berubah setelah pembaruan: tutup aplikasi sepenuhnya dan buka lagi; di komputer tekan Ctrl+F5. Pastikan versi di bawah Pengaturan > Umum sesuai.
